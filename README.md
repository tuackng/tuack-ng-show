# tuack-ng-show

这是一个使用 VHS 自动化生成 Tuack-NG 演示视频的尝试。

仍在开发中。

## 使用方法

你需要安装字体 `Maple Mono Normal NL NF CN`，可执行文件 `tuack-ng` 与 `typst`。

保证这个仓库根目录位于 `~/Documents/tuack-ng-show` 下，然后：

```shell
vhs ~/Documents/tuack-ng-show/main.tape
```

生成 `tuack-ng.mp4`。

推荐使用 [agentstation/vhs](https://github.com/agentstation/vhs)
